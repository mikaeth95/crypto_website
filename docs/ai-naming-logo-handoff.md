# AI Handoff: Product Naming And Logo Brief

## Purpose

Use this document as context for another AI that will generate:

- product name ideas
- shortlist recommendations
- logo concepts
- brand direction cues

The goal is not to redesign the app from scratch. The goal is to help another AI understand what this product actually does, who it is for, and what kind of identity would fit it.

## Product Summary

This product is a private crypto analytics dashboard and trading workspace.

It combines:

- portfolio tracking
- imported transaction history
- live multi-panel charts
- market browsing
- performance analytics
- per-user saved presets and preferences

It is not a public coin-price website and not a meme-style retail crypto app.

The product behaves more like:

- a personal trading desk
- a portfolio intelligence workspace
- a market monitoring command center

than a simple "crypto dashboard."

## What The Dashboard Does

The app currently includes these main sections:

### Dashboard

Gives the user a high-level overview of:

- portfolio value
- allocations
- top movers
- recent transactions

### Portfolio

Shows a table-driven view of holdings with:

- current values
- average buy prices
- profit/loss context

### Transactions

Lets the user import exchange CSV files and inspect:

- buys
- sells
- conversions
- deposits
- fees
- order and trade history

### Performance

Provides coin analytics such as:

- ATH distance
- volatility
- momentum
- price change windows

### Markets

Lets the user browse Crypto.com Exchange spot markets with filters and live market data.

### Live Charts

This is one of the strongest parts of the product.

The user can:

- monitor multiple charts at once
- save chart presets
- switch timeframes
- follow live price action
- use the app like a compact personal market desk

## Main Use Case

The main user is someone who wants one private place to:

- track their crypto holdings
- review imported trades
- monitor live markets
- compare assets
- keep a personal watch setup

This is not primarily for beginners who just want to check Bitcoin price.

It is better positioned for a user who wants:

- more control
- more monitoring depth
- more structure
- a more serious trading/workspace feel

## Product Personality

The identity should feel:

- serious
- premium
- technical
- focused
- sharp
- credible

It should not feel:

- childish
- loud
- meme-driven
- casino-like
- hype-first
- generic SaaS

## Brand Positioning

A good name and logo should support one of these positioning angles:

### 1. Portfolio Intelligence

Emphasis on clarity, insight, oversight, and decision support.

### 2. Market Command Center

Emphasis on monitoring, control, live movement, and trading-desk energy.

### 3. Private Operator Workspace

Emphasis on a personal but premium environment for serious crypto management.

## Target User

The likely target user is:

- crypto-native or crypto-familiar
- comfortable with charts and tables
- active enough to care about transactions and performance
- interested in a personal workspace, not a social product

This user probably values:

- signal over noise
- speed and clarity
- professional feel
- trust and control

## Current Product Characteristics

Important traits that should influence naming and logo ideas:

- authenticated private workspace
- portfolio + market data in one product
- multi-chart live monitoring
- imported transaction history
- dark, chart-friendly interface
- data-dense, table-heavy screens
- desktop-first workflow

## Naming Guidance

The name should ideally be:

- short to medium length
- easy to say
- easy to remember
- credible in a premium product context
- flexible enough to grow beyond a single exchange

The name should avoid being:

- too literal, like `Crypto Portfolio Dashboard`
- too gimmicky
- too trend-chasing
- too tied to one token or one exchange
- too close to gambling language

Words and themes that may fit:

- signal
- pulse
- desk
- watch
- flow
- vector
- atlas
- node
- grid
- command
- lens
- pilot
- harbor
- vault
- core

These are cues, not requirements.

## Logo Guidance

The logo should feel at home in:

- a dark sidebar
- a landing page hero
- a browser tab/favicon
- a chart-heavy product UI

It should work well as:

- a wordmark
- an icon mark
- a combined lockup

The visual idea should lean toward:

- precision
- motion
- structure
- signal
- navigation
- monitoring

Possible visual motifs:

- grid
- chart line
- radar sweep
- pulse/wave
- node network
- compass
- beacon
- cockpit/control cues
- abstract geometric mark

Avoid logo directions that feel:

- overly playful
- mascot-based
- cartoonish
- hyper-futuristic cliche
- neon-crypto-gimmick heavy

## Visual Environment

The current UI direction is:

- dark navy/slate backgrounds
- glass and panel layers
- blue accenting
- chart-first screens
- dense but polished tables

The future identity should still feel at home in that environment.

## Success Criteria

A strong outcome would produce:

- names that sound like real products
- a logo direction that feels premium and analytical
- an identity that supports charts, data, and monitoring
- branding that feels distinct without becoming theatrical

## Suggested Prompt For Another AI

```md
I have a working crypto analytics product and I want help generating name ideas and logo directions.

Here is what the product does:

- private authenticated crypto workspace
- portfolio tracking
- imported transaction history
- live multi-panel market charts
- market browsing
- performance analytics
- user-specific saved chart presets

The product feels more like a personal trading desk or portfolio intelligence workspace than a generic crypto dashboard.

The target user is someone who already understands crypto basics, wants a serious tool, and values monitoring, clarity, and control.

Please give me:

1. 20 strong product name ideas
2. your best 5 with reasoning
3. 5 logo concept directions that match the best names
4. guidance on which names feel most premium, memorable, and scalable

Important constraints:

- avoid childish or meme-like names
- avoid generic names like "Crypto Dashboard Pro"
- avoid branding that feels casino-like
- make it fit a dark, chart-heavy analytics product
- the name should still work if the product expands beyond one exchange
```
